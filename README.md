# Mister E AI V5
Six-part card content engine: Card Information; History; Listing Description; Social Media Post Ideas; Hashtags; Content Ideas.
Server-backed MVP. Accepts front/back images and sends them to a vision-capable OpenAI model through the Responses API. Keep the API key server-side.
Run: npm install, copy .env.example to .env, add OPENAI_API_KEY, then npm start.
